# Santa Cláusula — iFood Benefícios

Simulador de máquina de escrever para a campanha "Santa Cláusula" do iFood Benefícios.

Colaboradores podem escrever uma cartinha ao RH pedindo saldo livre no cartão de benefícios no lugar da cesta de Natal, com toda a experiência imersiva de digitar numa máquina real: som de teclas gravado, folha com template e carimbo "SANTA CLÁUSULA", máquina marsala que aparece ao ativar o modo máquina.

## Features
- Pop-up de abertura coleta nome, empresa, e-mail corporativo, nome e e-mail do RH
- Folha com template iFood Benefícios (logo em carimbo de tinta desbastado, labels datilografadas)
- Carimbo "SANTA CLÁUSULA" no canto superior da folha
- Som real de máquina de escrever (teclas, espaço, enter com ding, backspace)
- Modo máquina: alternância para mostrar/ocultar máquina de escrever vintage marsala
- Contador de linha/coluna com sino (bell) ao se aproximar da margem direita (como máquina real)
- Rodapé fixo com envio e pedido de assinatura virtual do RH
- Galeria de cartinhas exemplo da campanha
- Mobile responsivo

## Paleta (iFood Benefícios)
- Creme: #FDF8F1
- Marsala: #69022D
- Acqua: #91F5CD
- Branco: #FDFDFD

## Rodar localmente
```bash
python3 -m http.server 8787
```
Depois abra http://127.0.0.1:8787.
